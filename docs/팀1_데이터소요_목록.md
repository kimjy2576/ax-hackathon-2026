## 2. 본선 4주 필수 최소셋 (★만 추림)

1. 1D 해석 엔진 + 매뉴얼 — 확보됨
2. 냉매 물성 라이브러리 — 확보됨
3. 요소 컴포넌트 스펙 3종 (압축기 성능맵, 열교환기 사양, EEV·팬) — 세탁건조기 1개 모델분이면 충분
4. 검증된 baseline 해석 모델 1종 (또는 정합용 실측 데이터)
5. 요구사양서 샘플 2~3건 (PM 에이전트 입력 테스트용)
6. 컴포넌트 운전 한계 기준 (검증 룰 작성용)

→ 이 6개 중 1·2는 보유, 3·4·5·6은 세탁건조기 1개 기종 범위로 한정하면 팀 내부 자료만으로 확보 가능할 것으로 예상. 시스템 연동 없이 파일 기반으로 시작 가능한지가 확인 포인트.

## 3. Section 5 재작성 시 반영 원칙

- 시스템 실명이 확인된 항목만 "연동 예정 사내 시스템"에 기재하고, 나머지는 "활용 데이터 종류"에 데이터명으로만 기재 (없는 시스템명을 만들지 않는다)
- 본선은 파일 업로드/수동 반출 기반, 시스템 직접 연동은 확대 단계 조건으로 명시 (접근 승인 리스크 방어 유지)
- ①~⑤ 항목은 RAG 지식 자산 절에 명시해 "무엇을 학습하는가"를 구체화
